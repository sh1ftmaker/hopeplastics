# Hope Plastics website

A static, dependency-free site for Hope Plastics, Inc. (North Hollywood, CA).
Eight pages, hand-written HTML and CSS, self-hosted fonts, about 7 MB total
including every photo.

## Layout

```
build.py              assembles dist/ from src/ (Python 3 standard library only)
src/pages/*.html      one fragment per page; first lines hold title + description
src/assets/css/site.css
src/assets/js/site.js small-screen menu and the gallery viewer; site works without it
src/assets/fonts/     Archivo and Source Serif 4 (woff2, from Google Fonts)
src/assets/img/       photos recovered from the 2015 site, plus cutouts
dist/                 the deployable site (regenerated by build.py)
```

## Build and preview

```
python3 build.py
python3 -m http.server 8942 --directory dist
```

## Deploy

Upload the contents of `dist/` to any static host: GoDaddy's cPanel
`public_html`, Cloudflare Pages, Netlify, GitHub Pages or an S3 bucket. There
is no server code and no build step on the host.

## Editing content

Edit the fragment in `src/pages/` and rerun `build.py`. The shared header,
navigation and footer live in `build.py` (`LAYOUT` and `NAV`). Phone, fax,
address and the two contact names appear in the footer template and on
`contact.html` and `index.html`.

Gallery captions were written from the photographs and the old file names and
should be checked by Bill or Steve before the site goes live.
